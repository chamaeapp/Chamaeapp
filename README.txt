CHAMAÊ — PROTÓTIPO PWA
1. Este pacote é uma demonstração inicial.
2. Para testar, publique os arquivos em um serviço de hospedagem HTTPS.
3. Os anúncios e pedidos ficam no armazenamento local do navegador e não são compartilhados.
4. Ainda precisa de backend, autenticação, banco de dados online, moderação, privacidade e segurança antes de operar com usuários reais.
5. Não coloque senhas, chaves secretas ou dados pessoais neste repositório público.
